# 首页任务列表设计

## 目标

将首页连接到已有 Room 数据库，显示所有任务（包括暂停任务），并允许用户在列表中启用或暂停单个任务。

## 方案

Room DAO 提供按下次触发时间排序的 `Flow<List<TaskEntity>>`；`TaskRepository` 直接透传该流。`HomeViewModel` 将其转换为状态流，并在 IO 协程中调用既有 `TaskRepository.setEnabled`。Compose 首页接收已经面向展示映射的 `HomeTaskItem` 列表，避免 UI 理解持久化规则编码。

## 范围

- 任务卡显示名称、时间、简短规则和启停开关。
- 没有任何任务时保留现有空状态。
- “新建任务”继续显示占位提示；本阶段不创建或编辑任务。

## 排序与故障处理

有 `nextTriggerAt` 的任务按时间升序；没有下次触发时间的任务放在最后。暂停任务仍显示，便于重新启用。数据流为空或数据库尚无数据时显示空状态；启停由已有 Repository 调度闹钟，UI 不直接操作 `AlarmManager`。

## 验收

1. 已保存的启用和暂停任务均出现在首页。
2. 卡片正确展示每日规则与 24 小时时间。
3. 开关调用 Repository，并由其统一调度或取消闹钟。
