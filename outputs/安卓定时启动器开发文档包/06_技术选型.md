# 技术选型

## 1. 结论

| 领域 | 选型 | 原因 |
|---|---|---|
| 语言 | Kotlin | Android 官方优先支持；协程与空安全适合本项目。 |
| UI | Jetpack Compose + Material 3 | 声明式界面、动态取色、少 XML。 |
| 架构 | MVVM + Repository | 对个人项目足够清晰，不引入过度分层。 |
| 状态 | ViewModel + `StateFlow` | 生命周期感知，Compose 收集方便。 |
| 异步 | Kotlin Coroutines | 数据库、计算、网络均在协程中处理。 |
| 数据库 | Room 2.x（稳定分支）+ KSP | 保存任务、规则覆盖、日志与缓存。 |
| 偏好 | DataStore Preferences | 保存不适合关系型表的设置。 |
| 调度 | AlarmManager + PendingIntent + BroadcastReceiver | 系统级时间触发。 |
| 导航 | Navigation Compose | 单 Activity 页面导航。 |
| 网络（可选） | Retrofit + OkHttp + Kotlinx Serialization | 拉取节假日数据。 |
| DI | 手动构造 / `AppContainer` | 小型离线应用无需 Hilt。 |
| 测试 | JUnit、Turbine、Room Testing、Compose UI Test | 规则、数据库、界面各自可测。 |

## 2. SDK 基线

```kotlin
android {
    namespace = "com.example.timestart"
    compileSdk = 36

    defaultConfig {
        applicationId = "com.example.timestart"
        minSdk = 26
        targetSdk = 36
    }
}
```

`compileSdk/targetSdk 36` 对应 Android 16；Android Developers 当前配置指南明确给出这组值。`minSdk 26` 让 `java.time` 原生可用，降低日期计算和 desugaring 复杂度。

## 3. 依赖策略

- 使用 Android Studio 创建的 Compose 项目模板与 Compose BOM；所有库版本集中在 `gradle/libs.versions.toml`。
- 新建项目当天仅选择**稳定版**依赖；不要以本文写作时的临时版本号锁死项目。
- Room 采用稳定的 `androidx.room` 2.x；虽然 Room 3 已发布，但它面向 Kotlin Multiplatform 的迁移并非本项目所需。
- KSP 用于 Room 代码生成；不使用 kapt。
- 首个 MVP 不加入 Retrofit；节假日模式开发时再引入，保证离线闭环先可用。

## 4. Android 系统 API 对照

| API | 本项目用途 | 注意点 |
|---|---|---|
| `AlarmManager` | 注册下一次调度 | 精确 API 需检查 `canScheduleExactAlarms()`。 |
| `PendingIntent.getBroadcast` | 让系统在未来发送任务 ID | 使用稳定 `requestCode`，API 31+ 声明 `FLAG_IMMUTABLE`。 |
| `BroadcastReceiver` | 接收闹钟、开机、时间变更 | 不在 `onReceive` 做长网络请求。 |
| `PackageManager` | 查询可启动应用、构建启动 Intent | Android 11+ 受包可见性限制。 |
| `NotificationManager` | 启动失败或保底通知 | Android 13+ 需要 `POST_NOTIFICATIONS`。 |
| `PowerManager` | 只查询是否忽略电池优化 | 不默认请求白名单。 |

## 5. 明确不使用的方案

| 方案 | 不采用原因 |
|---|---|
| `Timer`、`Handler`、常驻循环 | 进程退出即丢失，无法跨重启。 |
| `WorkManager` 作精确定时 | 调度不保证在 18:00 精确运行。 |
| `setRepeating()` | 重复闹钟会随系统批处理漂移；应每次重算下一次。 |
| 常驻前台服务 | 增加电量和 Android 12+ 启动限制；不是本项目可靠性前提。 |
| `QUERY_ALL_PACKAGES` | 已安装应用列表属于敏感数据，且非必要。 |
| AccessibilityService | 超出“定时启动”范围，具有额外安全/审核风险。 |

## 6. 开发环境

- Android Studio：使用支持 API 36 的当前稳定版本。
- JDK：使用 Android Studio 嵌入的 JDK 17。
- 构建脚本：Gradle Kotlin DSL（`.kts`）。
- 代码规范：Kotlin 官方格式化；使用 `ktlint` 或 Android Studio 格式化二选一。
