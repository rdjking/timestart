# 功能规格说明（FSD）

## 1. 任务字段

每个任务由目标应用、触发时间、规则、有效期、执行策略和状态构成。字段物理定义见 [10_数据库设计与ER图.md](10_数据库设计与ER图.md)。

| 字段 | 规则 |
|---|---|
| 目标应用 | 保存 `packageName`、显示名称和图标版本信息；执行时重新向 PackageManager 查询。 |
| 时间 | 本地时区下的 `hour`（0–23）与 `minute`（0–59）。 |
| 规则 | 见下表；同一任务只选择一种主规则。 |
| 有效期 | 可选开始/结束日期；结束日期当天仍可触发。 |
| 执行模式 | `TRY_LAUNCH_THEN_NOTIFY`（默认）或 `NOTIFY_ONLY`。 |
| 启用状态 | 关闭即取消该任务现有闹钟；保留历史日志。 |

## 2. 规则语义

| `ruleType` | 示例 | 匹配定义 |
|---|---|---|
| `ONCE` | 2026-08-01 09:00 | 仅在指定本地日期时间执行一次。 |
| `DAILY` | 每天 18:00 | 每个自然日。 |
| `WEEKDAY` | 工作日 18:00 | 默认周一至周五；开启中国调休后以节假日资料优先。 |
| `WEEKEND` | 周末 10:00 | 默认周六、周日；开启中国调休后以节假日资料优先。 |
| `WEEKLY` | 周一、三、五 08:30 | `weekdaysMask` 至少含一日。 |
| `MONTHLY` | 每月 15 日 09:00 | 不存在该日期的月份跳过；不改为当月最后一天。 |
| `YEARLY` | 每年 12 月 25 日 09:00 | 保存月、日；2 月 29 日仅在闰年匹配。 |

## 3. 下一次触发计算

1. 以 `now` 的本地日期开始，最多向后搜索 400 天（年度 2 月 29 日允许搜索 1,500 天）。
2. 对每个候选日期，先检查有效期，再检查规则和可选节假日覆盖。
3. 候选时刻必须严格晚于 `now`；否则检查下一天。
4. 返回最早合法 `Instant`；找不到则置任务为 `EXHAUSTED` 并写日志。
5. 每次只向 AlarmManager 注册**一个**下一次闹钟；触发后再计算下一次，避免重复闹钟漂移。

## 4. 应用选择与启动

### 选择器

- 默认通过 `ACTION_MAIN` + `CATEGORY_LAUNCHER` 查询可启动 Activity，只展示结果集合。
- 用户搜索名称/包名；按应用名称排序。
- “手动输入包名”用于已知应用，但保存前必须验证存在可启动入口。
- 不使用 `QUERY_ALL_PACKAGES`；应用列表只请求与启动器意图匹配的可见应用。

### 触发执行

1. `AlarmReceiver` 用任务 ID 查询数据库。
2. 检查任务仍启用、规则仍匹配、目标包仍可启动。
3. 先计算并注册下次任务，避免进程在启动请求后死亡而遗失后续计划。
4. 建立 `getLaunchIntentForPackage(packageName)`；添加 `FLAG_ACTIVITY_NEW_TASK`；调用 `startActivity()`。
5. 将“已发起启动请求”写入日志。它不等同于“目标 App 已成功显示”。
6. 若没有启动入口、调用异常或策略为通知保底，发布含 `contentIntent` 的通知。

## 5. 页面与交互

| 页面 | 行为 |
|---|---|
| 首页 | 显示任务卡片、下次时间、开关、权限横幅与新建按钮。 |
| 编辑页 | 分步或单页表单；保存前实时验证。 |
| 应用选择页 | 搜索、选择、手动包名验证。 |
| 权限与可靠性页 | 显示精确闹钟、通知、电池优化状态及操作入口。 |
| 日志页 | 按任务过滤，支持复制与清理 30 天前的记录。 |

## 6. 校验与错误文案

| 场景 | 阻断 | 用户提示 |
|---|---|---|
| 未选择应用 | 是 | “请选择要启动的应用。” |
| 单次日期时间已过去 | 是 | “单次任务必须晚于当前时间。” |
| 每月日期为 0 或大于 31 | 是 | “请选择 1 到 31 日。” |
| 无精确闹钟权限 | 否 | “未获‘闹钟和提醒’授权，任务将不会精确执行。” |
| 目标应用不可启动 | 是（保存时）/否（执行时） | “未找到可启动入口，请重新选择应用。” |
| 节假日资料过期 | 否 | “节假日资料不可用，已按普通星期规则计算。” |

## 7. 删除与数据保留

- 删除任务：先取消 PendingIntent，再在同一数据库事务中删除任务及关联的规则参数；日志保留 30 天后自动清理。
- 停用任务：保留任务、规则和日志；`nextTriggerAt` 置空。
- 单次任务执行后：标记 `COMPLETED`，不自动删除。
