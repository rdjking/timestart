# 定时启动器实施计划

> 本计划面向从空 Android Studio 项目开始的实现。每项完成后运行对应测试并提交一次小粒度 Git 提交。

**目标：** 实现个人离线定时启动器 MVP，并对受系统限制的后台拉起提供透明的日志和通知保底。

**架构：** 单 Activity Compose + MVVM；Room 保存任务和日志；每项任务只注册下一次 AlarmManager 闹钟；Receiver 先重算后尝试启动。

**技术栈：** Kotlin、Compose Material 3、Room、Coroutines/Flow、AlarmManager、BroadcastReceiver、DataStore、JUnit。

## 全局约束

- `minSdk=26`、`compileSdk=36`、`targetSdk=36`。
- 不申请 `QUERY_ALL_PACKAGES`，不默认启动前台服务，不使用 AccessibilityService。
- 所有时间计算使用 `java.time`，持久化时间点为 UTC epoch milliseconds。
- UI 不得将 `startActivity()` 请求表述为目标应用“已成功显示”。

- [ ] 实现 `AlarmReceiver`：读取任务、验证、先重算登记、调用 `LaunchExecutor`、写日志。
